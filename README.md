# Игра Пятнашки с решателем

Проект показывает цельную реализацию игры Пятнашки для задания по дискретной математике. Пользователь может перемещать плитки вручную, перемешивать поле, возвращать его в исходное состояние и запускать решатель для текущей конфигурации.

Frontend сделан на React и TypeScript в легкой структуре tiny FSD. Интерфейс использует светлую минималистичную дизайн систему с крупными плитками, акцентом ac2954, мягким фоном F5F2EB и плавной анимацией пошагового решения.

Backend сделан на Java и Spring Boot. Он проверяет корректность и решаемость поля, запускает BFS для оптимального пути и DFS для демонстрации грубого перебора с ограничением глубины, после чего возвращает массив ходов и состояния поля для анимации.
